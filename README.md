# عهدة UUES — Petty Cash app

Mobile web app (PWA) for UUES staff to record custody (عهدة) invoices by voice or typing and export the UUES
EXPENSES REPORT form to Excel (one sheet per custody + Summary, A4 print-ready).

- Works on iPhone and Android; install with "Add to Home Screen".
- Data stays on the phone (localStorage / IndexedDB). Use the in-app backup to move it between phones.
- No server, no accounts.
